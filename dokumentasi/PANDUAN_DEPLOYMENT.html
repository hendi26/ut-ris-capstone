1
Push ke GitHub
Vercel dan Render membaca kode dari GitHub
GitHub
  1. Buat repository baru di github.com — misalnya ut-ris-capstone
  2. Buka terminal di folder project, jalankan:
cd "d:\Capstone UT\Fix\UT-RIS_Capstone_fixed"
git init
git add .
git commit -m "Initial commit: UT-RIS Capstone Project"
git remote add origin https://github.com/USERNAME/ut-ris-capstone.git
git branch -M main
git push -u origin main
Pastikan file .gitignore sudah ada dan menyertakan .env, __pycache__, node_modules, *.db
2
Setup Database PostgreSQL di Neon.tech
Database gratis, lebih stabil dari Render PostgreSQL free tier
Neon.tech
  1. Buka neon.tech → Sign up dengan GitHub
  2. Klik "New Project"
  3. Isi:
      • Project name: utris-capstone
      • Database name: utris
      • Region: pilih Singapore (ap-southeast-1) — paling dekat Indonesia
  4. Klik "Create Project"
  5. Setelah dibuat, copy Connection String — terlihat seperti ini:
postgresql://utris_owner:AbCdEfGh@ep-xxx.ap-southeast-1.aws.neon.tech/utris?sslmode=require
Simpan connection string ini — akan dipakai di Render nanti.
3
Deploy Backend ke Render.com
FastAPI Python — auto-deploy dari GitHub
Render.com
  1. Buka render.com → Sign up dengan GitHub
  2. Klik "New +" → pilih "Web Service"
  3. Pilih repository ut-ris-capstone dari GitHub
  4. Isi konfigurasi:
FieldValue
Nameutris-backend
Root Directorybackend

Build Commandpip install -r requirements.txt
Start Commanduvicorn app.main:app --host 0.0.0.0 --port $PORT
Instance TypeFree

Tambahkan Environment Variables:
KeyValue
ENVIRONMENTproduction

ACCESS_TOKEN_EXPIRE_MINUTES30

  1. Klik "Create Web Service" — Render akan build dan deploy otomatis
  2. Tunggu hingga status menjadi Live (5–10 menit)
  3. Catat URL backend: https://utris-backend.onrender.com
Test: buka https://utris-backend.onrender.com/health — harus return {"status":"healthy"}
4
Deploy Frontend ke Vercel
React + Vite — auto-deploy, CDN global
Vercel
  1. Buka vercel.com → Sign up dengan GitHub
  2. Klik "Add New Project" → Import repository ut-ris-capstone
  3. Konfigurasi project:
FieldValue

Tambahkan Environment Variables di Vercel:
KeyValue

  1. Klik "Deploy" — build otomatis berjalan (~2 menit)
  2. Setelah selesai, catat URL Vercel: https://utris-capstone.vercel.app
Test: buka URL Vercel → halaman login UT-RIS harus muncul
5
Update CORS di Render
Izinkan frontend Vercel mengakses backend Render
  1. Buka Render dashboard → Service utris-backend → Environment
  2. Update value CORS_ORIGINS dengan URL Vercel yang sebenarnya:
CORS_ORIGINS=https://utris-capstone.vercel.app
  1. Klik Save Changes → Render akan auto-redeploy (~2 menit)
  2. Test login dari URL Vercel dengan akun admin / admin123
Jika URL Vercel berbeda (misal ada angka random), sesuaikan value CORS_ORIGINS dengan URL yang benar.
6
Seed Data Demo di Production
Isi database production dengan data demo untuk presentasi

Admin user sudah di-seed otomatis saat startup. Untuk data demo (pasien, jadwal, pemeriksaan, laporan), jalankan script seed via Render Shell:

  1. Buka Render dashboard → Service utris-backend → Shell
  2. Jalankan perintah berikut di shell Render:
python -c "
import asyncio
from app.db.session import AsyncSessionLocal
from app.models.user import User, UserRole
from app.core.security import get_password_hash
from sqlalchemy import select

async def seed():
    async with AsyncSessionLocal() as db:
        # Cek admin sudah ada
        r = await db.execute(select(User).where(User.username=='admin'))
        admin = r.scalar_one_or_none()
        if admin:
            print('Admin sudah ada, ID:', admin.id)
        else:
            print('Admin belum ada!')

asyncio.run(seed())
"
Akun yang tersedia setelah deploy:
admin / admin123 (auto-seeded saat startup)
Data demo lengkap (5 pasien, jadwal, dll) perlu di-seed manual via Render Shell menggunakan script seed_demo.py yang ada di folder backend.

Troubleshooting Umum
Solusi masalah yang sering muncul
MasalahPenyebabSolusi
Login gagal CORS error CORS_ORIGINS belum di-update Update env var CORS_ORIGINS di Render dengan URL Vercel yang benar
Backend 500 saat startup DATABASE_URL salah atau DB belum siap Cek Render logs, pastikan Neon connection string benar dan include ?sslmode=require
Halaman blank di Vercel Build error atau env var kurang Cek Vercel build logs, pastikan VITE_API_BASE_URL sudah diisi
Request timeout 30 detik Render free tier "tidur" Normal — tunggu 30 detik untuk cold start. Pertimbangkan upgrade ke Starter
PDF tidak ter-download ReportLab tidak terinstall Pastikan reportlab==4.2.2 ada di requirements.txt
Alembic migration error Schema belum sesuai Jalankan alembic upgrade head manual di Render Shell
