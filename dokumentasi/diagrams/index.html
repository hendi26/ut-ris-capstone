Arsitektur Sistem
Three-tier architecture: Presentation (React), Business Logic (FastAPI), Data (PostgreSQL + Orthanc PACS). Termasuk Clean Architecture 4 layer backend.
Three-Tier Clean Architecture Tech Stack
🔄
Alur Kerja Radiologi
Sequence diagram multi-aktor lengkap dari permintaan pemeriksaan hingga pasien mengunduh PDF laporan. Termasuk state diagram Appointment, Study, dan Report.
Sequence Diagram State Machine 4 Aktor

RBAC & Autentikasi
Alur JWT dual-token, token blacklist, BCrypt. Matriks hak akses lengkap 5 peran × semua resource. Sesuai amanat PMK 24/2022.
5 Roles JWT + Blacklist PMK 24/2022

Integrasi PACS DICOMweb
Arsitektur koneksi RIS ↔ Orthanc via QIDO-RS & WADO-RS. Strategi hybrid live/mock fallback. Format data DICOM JSON, daftar 5 mock studies simulasi.
QIDO-RS WADO-RS Hybrid Fallback

API Reference
Dokumentasi lengkap 35+ endpoint REST API: auth, users, patients, appointments, studies, reports, patient portal, PACS, dashboard. Dilengkapi method, path, dan role akses.
