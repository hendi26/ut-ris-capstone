Strategi Hybrid Live/Mock: Sistem mencoba koneksi ke Orthanc dengan timeout 5 detik. Jika berhasil → data DICOM nyata. Jika gagal (ConnectError) → otomatis fallback ke 5 study simulasi dalam format DICOMweb JSON standar. Tidak ada error 503 yang terekspos ke user.

API Endpoints PACS

  • GET
    /pacs/health
    Status koneksi Orthanc. Return: connected / simulated
  • GET
    /pacs/studies
    QIDO-RS: Cari studies by PatientID / AccessionNumber / date
  • GET
    /pacs/studies/by-accession/{no}
    Link RIS ↔ PACS via accession number. Return data RIS + PACS
  • GET
    /pacs/studies/{uid}/series
    QIDO-RS: Daftar series dalam satu study DICOM
  • GET
    /pacs/studies/{uid}/metadata
    WADO-RS: Metadata DICOM lengkap (tanpa pixel data)
